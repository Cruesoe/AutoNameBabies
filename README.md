# Auto Name Babies

Automatically names babies when they are born, removing the naming prompt while keeping the usual birth letter.

## Features

- First names use the normal culture and xenotype-based generator.
- Choose the father's, mother's, or a random parent's surname.
- Surnames can follow Ideology marriage-name rules.
- Supports temporary and incomplete ideologies, including the VFE Tribals Wild Men start.
- Babies still named "Baby" in existing saves are named when the save loads.
